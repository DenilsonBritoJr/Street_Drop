# Street Drop

## 🎓 Sobre o Projeto 

Este repositório contém o **Street Drop**, um projeto de cunho estritamente acadêmico desenvolvido por **Denilson Brito Junior**, estudante do 1º semestre do curso de Desenvolvimento de Software Multiplataforma (DSM) na FATEC


## OBJETIVO
Escopo: Desenvolver uma plataforma web responsiva de blog focada no nicho de streetwear, permitindo a publicação, categorização, navegação intuitiva e busca eficiente de artigos de moda e cultura urbana 

Problema: (dor do cliente): Os entusiastas e consumidores de moda urbana/streetwear enfrentam a falta de uma plataforma centralizada e moderna que ofereça análises aprofundadas sobre tendências, marcas e lançamentos (drops), resultando em uma experiência de navegação fragmentada e superficial em portais genéricos. 


### Backlog do Produto

| Rank | Prioridade | User Story | Estimativa |
|:---:|:---:|---|:---:|
| 1 | Alta | Como leitor, desejo visualizar artigos em destaque e lançamentos de streetwear para me manter atualizado sobre a cultura e marcas. | 6h |
| 2 | Alta | Como leitor, desejo navegar no site de forma responsiva (mobile e desktop) para ler os conteúdos confortavelmente em qualquer dispositivo. | 4h |
| 3 | Média | Como leitor, desejo buscar artigos por palavras-chave ou temas para encontrar rapidamente conteúdos específicos de meu interesse. | 2h |
| 4 | Média | Como leitor, desejo filtrar postagens por categorias (ex: Drops, Sneakers, Marcas, Moda Urbana) para navegar por tópicos do meu interesse. | 4h |
| 5 | Baixa | Como leitor, desejo visualizar uma galeria visual com links para compras/onde posso encontrar os itens abordados no artigo. | 3h |
